# AI Market Discover

Google Discover × Bloomberg × TradingView を組み合わせた AI金融ダッシュボード Chrome拡張機能。

## 機能
- 🔥 Know Today（今日知るべきニュース）
- 📊 業界別パフォーマンス
- 📈 決算Hub
- 📅 経済カレンダー
- 📰 AIニュースクラスタリング
- ⭐ ウォッチリスト

## セットアップ
```bash
npm install
cp .env.example .env
npm run dev
```

## ビルド
```bash
npm run build
```
`dist/`フォルダをChromeの拡張機能管理ページからロード。
